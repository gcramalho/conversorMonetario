# Conversor de Valores em Java
Um projeto de console que converte valores entre moedas utilizando taxas de câmbio em tempo real via API.

<hr>

📊 Funcionalidades

✔️ Conversão entre 6 pares de moedas:

USD (Dólar) ↔ ARS (Peso Argentino)

USD ↔ BRL (Real Brasileiro)

USD ↔ COP (Peso Colombiano)

✔️ Atualização automática das taxas via Exchange Rate API
✔️ Interface simples no console

<hr>

🛠️ Tecnologias e Pré-Requisitos

Java 11+

GSON (para manipulação de JSON)

HttpClient (requisições HTTP)

Conta na Exchange Rate API (para obter uma chave de API gratuita)
